# 髋关节扭矩动态模型训练与推理接入

## 1. 接入范围

本次把真机阶跃实验辨识出的执行器通道加入仿真：

\[
\tau_{\mathrm{PD}}
\longrightarrow
\tau_{\mathrm{applied}}.
\]

它只描述理论 PD 扭矩的延迟、建立过程和幅值衰减，不替代 URDF 惯量、关节摩擦、阻尼、接触或多体耦合。模型只在 Isaac Gym 训练/play 和 MuJoCo sim2sim 中使用；真机自身已经包含执行器动态，部署端不应再次叠加。

## 2. 分关节模型

| 关节 | 模型 | 延迟/ms | 时间常数/ms | 增益 |
| --- | --- | ---: | ---: | ---: |
| 左髋 Pitch | FOPDT | 7.935 | 3.7819 | 0.79683 |
| 右髋 Pitch | FOPDT | 6.937 | 4.5823 | 0.79310 |
| 左髋 Roll | FOPDT | 7.828 | 4.9369 | 0.86318 |
| 右髋 Roll | FOPDT | 7.042 | 6.5210 | 0.90500 |
| 左髋 Yaw | 静态增益 | — | — | 0.52263 |
| 右髋 Yaw | 静态增益 | — | — | 0.51651 |

FOPDT：

\[
\tau_a(s)=\frac{\eta}{\tau_m s+1}e^{-T_ds}\tau_{\mathrm{PD}}(s).
\]

离散实现按 1 ms 物理步更新，非整数延迟采用相邻历史样本线性插值，一阶环节采用零阶保持的精确离散系数：

\[
\alpha=1-e^{-\Delta t/\tau_m},\qquad
\tau_a[k]=\tau_a[k-1]+\alpha\left(\eta\tau_d[k]-\tau_a[k-1]\right).
\]

Yaw 静态增益：

\[
\tau_a[k]=\eta\tau_{\mathrm{PD}}[k].
\]

Yaw 的阶跃实验仍测到约 6～7 ms 动态；这里采用静态增益是因为此前 100 Hz 行走数据的分关节验证选择了该模型，不等于证明真实 Yaw 没有延迟。

## 3. 控制链路

训练和 Isaac Gym play：

```text
当前策略 action
  → 关节目标位置
  → 理论 PD 扭矩
  → episode 固定的 torque_multiplier
  → 髋关节静态增益/FOPDT
  → 仿真摩擦
  → 扭矩限幅
  → PhysX
```

已建模髋关节不再经过通用 action 延迟，避免 action 延迟和 FOPDT 扭矩延迟重复累计。脚踝仍沿用原来的 5～8 ms 最终 PD 扭矩延迟；膝关节暂时沿用通用 action 延迟。

`torque_multiplier` 改为只在环境 reset 时采样一次。原代码又在每个物理步重新采样，会产生没有实验依据的 1 kHz 乘性扭矩噪声，并破坏 FOPDT 的建立过程。

MuJoCo sim2sim 使用同一张配置表和同一离散模型，并分别记录 `ideal_cmd_dof_torque[*]` 与经过模型后的 `cmd_dof_torque[*]`，便于核对。
